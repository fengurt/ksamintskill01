# Beauty bar — the half a gate cannot check

Read once per deck. Everything measurable already lives in `gate_layout.py`;
this file is only what is left.

## One decision per page
If the page cannot answer "tomorrow, do what?", it is a document page. Delete it
or merge it. The `claim` field is the test — if writing it under 42 characters
is impossible, the page is carrying two ideas.

## Spend boldness once
Each page has exactly one focal point: the claim, the figure, or the number.
Everything else is quiet. A page with two competing focal points reads as busy
even at a perfect fill ratio.

## The deck is a poster sequence, not a document
Type is a share of canvas height, never a desktop px habit. Generous margins,
hairline rules, one accent. If it looks like a Bootstrap admin panel, it fails
regardless of what the gate says.

## Numbers are the subject
Mono, tabular figures, right-aligned in tables. A number below its reporting
threshold gets hatched, never hidden. A proxy metric gets watermarked, never
presented as measured.

## Rhythm
Do not run more than three consecutive pages of the same type. If the plan does,
the source material was chunked too uniformly — go back to `longdoc2mdpages`
rather than decorating your way out of it.

## Restraint
Before shipping, look at the deck at thumbnail size and remove one thing from
the busiest page.
