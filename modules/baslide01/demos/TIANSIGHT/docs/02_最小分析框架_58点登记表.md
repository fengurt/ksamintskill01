# 侍天 TIANSIGHT · 智能分析报告系统
## 卷二：最小分析框架登记表（58 分析点 · 机器可读）

> 本表是整个自动化系统的**唯一真源**。`TIANSIGHT.registry.json` 是它的机器副本——改表即改系统，不改代码。
> 列义：**数据输入** = 字段级依赖（规范字段 ID）｜**框架位置** = 依赖层级 L0–L6｜**支持决策** = 看完这页明天做什么｜**报告页面** = 页 ID + 版式｜**图元** = D3 图元名｜**频率** = 出具周期。
