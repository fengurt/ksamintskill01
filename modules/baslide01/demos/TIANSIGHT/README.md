# 侍天 TIANSIGHT · 智能分析报告系统框架

## 打开方式

```bash
# from repo root
bash scripts/dev-up.sh
# open http://127.0.0.1:<port>/demos/TIANSIGHT/
```

直接双击 `index.html` 也可运行（d3 走 CDN，需联网）。首屏自动载入演示数据。

## 六阶段流水线

① 接入 INGEST → ② 对齐 ALIGN → ③ 门禁 GATE → ④ 计算 COMPUTE → ⑤ 渲染 RENDER → ⑥ 收敛 CONVERGE

第 ②③ 层是本系统与通用 BI 的分野。②做不好，客户每次要手工映射 40 个字段；
③做不好，系统照样出图，但结论是错的。

## 接入自己的数据

拖拽 CSV / TSV 到接入区即可。系统会：

1. 判定表角色（账单明细 / 账单表头 / 品项索引表 / 会员消费），给置信度与次选
2. 逐列双通道打分：列名相似度 0.55 + 值特征签名 0.45
   - ≥0.85 自动绑定　0.60–0.85 进人工裁定队列　<0.60 进缺口清单
3. 列出该表缺失的必填字段 —— 这份清单可直接作为向客户索要数据的邮件正文
4. 用实测上下文跑 11 条门禁，产出 58 格解锁矩阵
5. 只渲染解锁的页面，降级页带水印，阻断页不出

## 三条不可绕过的约束

- **跨口径相除抛错**：`Q` 类携带口径标记，A÷B 直接 `BasisMismatchError`，不静默出数
- **合计必须闭合**：`assertClosed()` 失败即拒绝渲染，宁可不出图也不出「35 个 SKU 无归属」的图
- **零值 ≠ 缺口**：零值格只在基数达阈值时才标机会，防止系统自造伪洞察
